# Create assessment from form

App: [zapier-praxicraft-assess](https://github.com/praxicraft-platform/zapier-praxicraft-assess)
Docs: https://docs.praxicraft.com/zapier
## Steps
1. Trigger: Typeform / Google Form
2. Action: Praxicraft Assess → Create Assessment (title from form)
3. Optional: Attach Cases action if available
4. Slack “Assessment {{slug}} created”
