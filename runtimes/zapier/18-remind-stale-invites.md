# Remind stale invites

App: [zapier-praxicraft-assess](https://github.com/praxicraft-platform/zapier-praxicraft-assess)
Docs: https://docs.praxicraft.com/zapier
## Steps
1. Schedule daily
2. List invitations (filter pending / older than N days) via Assess search/list action
3. Loop: Remind invitation
4. Slack summary count
