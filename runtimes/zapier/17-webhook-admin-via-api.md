# Register webhook via Zapier

App: [zapier-praxicraft-assess](https://github.com/praxicraft-platform/zapier-praxicraft-assess)
Docs: https://docs.praxicraft.com/zapier
Zapier’s New Assess Event manages subscriptions for you.
For custom URLs, prefer CLI/SDK `08-webhook-admin` or n8n trigger activation.

If you must: Webhooks by Zapier Catch Hook URL → register that URL in Assess Developer → Destinations / webhooks API.

## Scenario
`08-webhook-admin`
